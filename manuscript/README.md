# Manuscript analyses

Reproducibility materials for the analyses reported in the manuscript. Everything reuses the
repository's core code in `R/` (`simulator_scenarios.r`, `temporalVarGuid.r`).

```
manuscript/
  R/  Simulation
        04_sim_A_to_D.R                      Models A-D  (ARX/ARXp x GARCH/GARCHX), Bias & RMSE
        01_sim_add_EF.R                      Models E (ARXp-GARCHX) & F (AR-GARCH)
      WESAD
        05_wesad_main.R                      Main result: variance-aware risk score vs raw HR_mean
        02_wesad_ablation_B_vs_D.R           Ablation: covariates in the variance (D) vs not (B)
        03_supervised_on_argarch_residuals.R Supervised classifiers on AR-GARCH residuals (LOSO)
      Figures
        make_figures.R                       Regenerate the manuscript figures (ggplot, no titles)
  python/  wesad_reanalyses.py               Clustered-bootstrap AUC CIs, class counts,
                                             threshold sensitivity, calibration, feature list
  data/    dat_fit.csv, label_tbl.csv, risk_scores.csv,
           rep_raw_s15t120_by_rep_100reps.csv, rep_raw_s15t240_by_rep_100reps.csv
  outputs/ result tables + figures/ (regenerated by the scripts above)
```

## Estimator
All scripts `source("R/temporalVarGuid.r")` — the penalized panel ARX-GARCHX estimator used to
produce the reported results, exposing `lmvt()` and `predict.lmvt()`.

## Run (from the repository root)
```bash
# Simulation (each ~30 min; parallel, 100 reps, T in {120, 240})
Rscript manuscript/R/04_sim_A_to_D.R           # Models A-D  -> outputs/sim_ABCD_*.csv
Rscript manuscript/R/01_sim_add_EF.R           # Models E, F -> outputs/sim_EF_*.csv

# WESAD
Rscript manuscript/R/05_wesad_main.R           # risk score vs raw HR_mean (headline AUCs)
Rscript manuscript/R/02_wesad_ablation_B_vs_D.R
Rscript manuscript/R/03_supervised_on_argarch_residuals.R
python  manuscript/python/wesad_reanalyses.py  # bootstrap CIs, calibration, sensitivity

# Figures (run last: reads the outputs above)
Rscript manuscript/R/make_figures.R
```

## What reproduces what
- **Simulation table (Models A-F).** `04_sim_A_to_D.R` regenerates Models A-D from scratch; 
  `01_sim_add_EF.R` adds Models E and F under the identical generator, seeds, and tuning.
  Both report Bias and RMSE of the estimated exceedance risk across Scenarios 1-4.
- **WESAD headline.** `05_wesad_main.R` reproduces the variance-aware risk-score AUC and
  the raw `HR_mean` baseline, using each subject's 70th-percentile threshold `c_s(0.70)`.
- **WESAD ablation & robustness.** `02` (covariates in the variance or not) and `03` (supervised
  baselines on AR-GARCH residuals, LOSO); `wesad_reanalyses.py` adds participant-clustered bootstrap
  confidence intervals, calibration, and threshold sensitivity.

## Data (`data/`)
- `dat_fit.csv` (15 subjects x 77 chest features) and `label_tbl.csv` (label 2 = stress): the WESAD
  model input. `risk_scores.csv`: a saved fit (muhat/sigmahat) for the bootstrap CI, threshold, and
  calibration analyses.
- `rep_raw_s15t{120,240}_by_rep_100reps.csv`: per-replication A-D simulation results
  (100 reps); `04_sim_A_to_D.R` regenerates these.
