# Manuscript analyses

Reproducibility materials for the analyses reported in the manuscript. Everything reuses the
repository's core code in `R/` (`simulator_scenarios.r`, `temporalVarGuid.r`).

```
manuscript/
  R/       01_sim_add_EF.R                       Simulation Models E (ARXp-GARCHX) & F (AR-GARCH)
           02_wesad_ablation_B_vs_D.R            WESAD ablation: covariates in variance (D) vs not (B)
           03_supervised_on_argarch_residuals.R  Supervised classifiers on AR-GARCH residuals (LOSO)
           make_figures.R                        Regenerate the manuscript figures (ggplot, no titles)
  python/  wesad_reanalyses.py                   Clustered-bootstrap AUC CIs, class counts,
                                                 threshold sensitivity, calibration, feature list
  data/    dat_fit.csv, label_tbl.csv, risk_scores.csv,
           rep_raw_s15t120_by_rep_100reps.csv, rep_raw_s15t240_by_rep_100reps.csv
  outputs/ result tables + figures/ (regenerated by the scripts above)
```

## Estimator
All scripts `source("R/temporalVarGuid.r")` — the single-stage penalized panel ARX-GARCHX estimator,
identical to the `varGuidTS` package's `lmvt`. All reported results use this single-stage estimator.

## Run (from the repository root)
```bash
Rscript manuscript/R/01_sim_add_EF.R                        # ~30 min (parallel, 100 reps)
Rscript manuscript/R/02_wesad_ablation_B_vs_D.R
Rscript manuscript/R/03_supervised_on_argarch_residuals.R
python  manuscript/python/wesad_reanalyses.py
Rscript manuscript/R/make_figures.R                        # run last: reads the outputs above
```

## Data (`data/`)
- `dat_fit.csv` (15 subjects x 77 chest features) and `label_tbl.csv` (label 2 = stress): the WESAD
  model input. `risk_scores.csv`: the saved fit (muhat/sigmahat) used for the bootstrap CIs, threshold,
  and calibration analyses.
- `rep_raw_s15t{120,240}_by_rep_100reps.csv`: the per-replication A-D simulation results (100 reps);
  the six-model figure places E and F next to these.

## Software
R 4.5.3; glmnet 5.0; pROC 1.19.0.1; randomForest 4.7.1.2; gbm 2.2.3; caret 7.0.1.
