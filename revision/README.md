# JTRM minor-revision analyses (JTRM-D-26-10410)

Self-contained replication of the analyses added in response to review. Everything reuses the
repo's existing core code in `R/` (`simulator_scenarios.r`, `temporalVarGuid.r`); the method did
not change.

```
revision/
  R/       01_sim_add_EF.R                  Models E (ARXp-GARCHX) & F (AR-GARCH) for Table S1
           02_wesad_ablation_B_vs_D.R       WESAD ablation: covariates in variance (D) vs not (B)
           03_supervised_on_argarch_residuals.R  supervised classifiers on AR-GARCH residuals
           04_make_revision_figures.R       regenerate the revision figures (ggplot, no titles)
  python/  wesad_reanalyses.py              clustered-bootstrap CIs, counts, threshold leak, calibration, 77-feature list

           rep_raw_s15t120_by_rep_100reps.csv, rep_raw_s15t240_by_rep_100reps.csv
  outputs/ result tables + figures/ (regenerated by the scripts above)
```

## Run (from the repository root)
```bash
Rscript revision/R/01_sim_add_EF.R                        # ~30 min (parallel, 100 reps)
Rscript revision/R/02_wesad_ablation_B_vs_D.R
Rscript revision/R/03_supervised_on_argarch_residuals.R
python  revision/python/wesad_reanalyses.py
Rscript revision/R/04_make_revision_figures.R            # run last: reads the outputs above
```

## Data provenance (`data/`)
- `dat_fit.csv` (15 subjects × 77 chest features) and `label_tbl.csv` (label 2 = stress): the WESAD
  model input used in the paper. `risk_scores.csv`: the saved Model-D fit (muhat/sigmahat) used for
  the clustered CIs, threshold, and calibration re-analyses.
- `rep_raw_s15t{120,240}_by_rep_100reps.csv`: the published per-replication A–D simulation results
  (100 reps); the six-model figure places E/F next to these.

## Estimator (important — repo file replaced)
The paper's analyses were all run with `temporalVarGuid1.r`, a **two-stage** estimator (Stage 1
fits the mean + GARCH with the variance covariates excluded; Stage 2 estimates the variance-covariate
effects γ by a weighted, L1-penalized regression of the residual variance on the covariates). The
version previously in this repo (`R/temporalVarGuid.r`) was a *different* single-stage implementation
and did **not** reproduce the paper. This update ships the paper's estimator as `R/temporalVarGuid.r`
(replacing the old file), so the whole repo now reproduces the paper. Supplement Algorithm S1 has been
updated to describe this two-stage scheme.

## Key results (final)
Six-model simulation: A–D unchanged, F far worst, E≈D. WESAD ablation: B≈D, both ≫ raw HR (0.868).
Participant-clustered bootstrap ΔAUC(risk−HR) 95% CI [0.031, 0.094] (excludes 0). Threshold-leak:
0.936 → ~0.88 with a leak-free burn-in threshold. Supervised on AR-GARCH residuals: ≤0.004 AUC change.
